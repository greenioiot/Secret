## Goal
On-device web app (Qualcomm IQ9): record Thai meetings → transcribe (high accuracy) → summarize → email. All data archived locally.

## Decisions
- Everything stored on device (no cloud storage). Summary LLM must run locally unless user later approves cloud.
- Web app served from the device (browser UI on LAN/localhost).
- Ubuntu 24.04 confirmed. Live captions wanted, plus a setting to choose after-the-meeting-only mode.
- Email/SMTP deferred: for now save results and show them on screen in the web UI (P7 postponed).
- Resumable: every job is checkpointed; this file records project status.

## Architecture
```
Browser UI (record / list / review / send)
        │ HTTPS + WebSocket
FastAPI backend ── SQLite (jobs, meetings, email log)
        │
Worker (systemd) – checkpointed stages:
  1 recorded → 2 enhanced/VAD → 3 diarized → 4 transcribed → 5 summarized → 6 emailed
        │
Data dir /var/lib/secret/meetings/<id>/
  audio.raw.wav, audio.16k.wav, chunks/, transcript.json, transcript.md,
  summary.md, email.eml, state.json
```
Resume rule: the worker reads `state.json` per meeting and restarts at the first incomplete stage; audio is written in rolling chunks so a crash loses at most a few seconds.
